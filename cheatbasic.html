C Cheat Sheet: The Basics

Data Types

  • int: For whole numbers (e.g., 10, -50).
  • float: For single-precision floating-point numbers (e.g., 3.14).
  • double: For double-precision floating-point numbers. More precise.
  • char: For a single character (e.g., 'a').
  • char name[]: For a string of characters.

Common Operators

  • Arithmetic: +, -, *, /, % (modulo)
  • Relational: ==, !=, >, <, >=, <=
  • Logical: && (AND), || (OR), ! (NOT)
  • Assignment: =, +=, -=, *=, /=

Control Structures

If-Else Statement

if (condition) {\n  // code to run if true\n} else {\n  // code to run if false\n}

For Loop

for (int i = 0; i < 5; i++) {\n  // code to repeat\n}

While Loop

while (condition) {\n  // code to repeat\n}
