C Cheat Sheet: Advanced Topics

Pointers

A variable that stores the memory address of another variable.

// Declaration\nint *ptr;\n\n// Assignment\nint var = 10;\nptr = &var;\n\n// Dereferencing (get value)\nprintf("%d", *ptr); // Prints 10

Structures (struct)

A user-defined data type to group different data types.

struct Student {\n  char name[50];\n  int id;\n};\n\n// Usage\nstruct Student s1;\ns1.id = 123;

File I/O

Functions to interact with files on the disk.

// Pointer to a file\nFILE *fptr;\n\n// Open a file for writing ("w")\nfptr = fopen("filename.txt", "w");\n\n// Write to file\nfprintf(fptr, "Hello File!");\n\n// Close the file\nfclose(fptr);
